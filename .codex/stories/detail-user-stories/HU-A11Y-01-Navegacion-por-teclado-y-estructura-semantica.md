# HU-A11Y-01 — Navegación por teclado y estructura semántica

**Sprint:** 3  
**ID de Azure DevOps:** [140](https://dev.azure.com/CodeFactory-2026-2/EBP07%20-%20Plataforma%20de%20Reservas%20de%20Servicios/_workitems/edit/140)  
**Fuente:** Inventario recuperado del chat «Inventario HU Sprint 3»; asociado al elemento de Azure.

## Historia

Como cliente con discapacidad visual o motora, quiero completar el inicio de sesión, la búsqueda de servicios, la reserva y la consulta de mis reservas usando solo el teclado y un lector de pantalla, para reservar sin depender de otra persona.

## Criterios de aceptación registrados en Azure

- Navegación mediante teclado

- Dado que me encuentro utilizando la plataforma,

- Cuando navego por sus diferentes secciones utilizando únicamente el teclado,

- Entonces puedo acceder a las opciones, formularios y funcionalidades principales sin necesitar un mouse.

- Identificación de elementos de la plataforma

- Dado que utilizo un lector de pantalla,

- Cuando navego por la plataforma,

- Entonces puedo identificar los títulos, botones, campos y opciones disponibles de manera comprensible.

- Navegación durante una reserva

- Dado que deseo realizar o consultar una reserva,

- Cuando utilizo herramientas de asistencia para navegar por el proceso,

- Entonces puedo reconocer los pasos y las opciones disponibles sin perder el contexto de la operación.

## Observaciones de análisis

Los criterios anteriores se conservan como fueron proporcionados por Azure DevOps. Las decisiones que no estén especificadas se registran como preguntas en el análisis asociado; esta ficha no agrega reglas nuevas.
