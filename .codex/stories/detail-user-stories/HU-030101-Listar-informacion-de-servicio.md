# HU-030101 — Listar información de servicio

**Fuente:** Azure DevOps, PBI 62, Sprint 2.

## Historia

Como cliente, quiero consultar la información detallada de un servicio seleccionado, para conocer sus características antes de realizar una reserva.

## Criterios de aceptación

- El cliente puede seleccionar un servicio desde resultados de búsqueda o listados.
- Al seleccionarlo, se muestra una ficha detallada.
- La ficha muestra como mínimo nombre, tipo o categoría, duración, precio y descripción.
- Muestra las imágenes asociadas al servicio.
- Si hay varias imágenes, permite recorrerlas mediante un carrusel.
- Permite identificar el negocio que ofrece el servicio.
- Incluye una opción para iniciar el proceso de reserva.
- Solo muestra la información registrada para el servicio seleccionado.
