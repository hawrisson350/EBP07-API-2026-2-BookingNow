# HU-070102 — Exportar reportes en PDF

**Sprint:** 3  
**ID de Azure DevOps:** [94](https://dev.azure.com/CodeFactory-2026-2/EBP07%20-%20Plataforma%20de%20Reservas%20de%20Servicios/_workitems/edit/94)  
**Fuente:** Inventario recuperado del chat «Inventario HU Sprint 3»; asociado al elemento de Azure.

## Historia

Como administrador o proveedor del negocio, quiero exportar los reportes generados en formato PDF, para conservar, compartir o consultar la información fuera de la plataforma.

## Criterios de aceptación registrados en Azure

- El sistema permite exportar el reporte generado en formato PDF.

- El documento contiene la información correspondiente a los filtros seleccionados.

- El PDF presenta un formato organizado y legible.

- El documento incluye el tipo de reporte y el período consultado.

## Observaciones de análisis

Los criterios anteriores se conservan como fueron proporcionados por Azure DevOps. Las decisiones que no estén especificadas se registran como preguntas en el análisis asociado; esta ficha no agrega reglas nuevas.
