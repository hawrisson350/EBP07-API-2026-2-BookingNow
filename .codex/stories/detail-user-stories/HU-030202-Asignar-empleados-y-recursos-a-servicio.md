# HU-030202 — Asignar empleados y recursos a un servicio

**Fuente:** Azure DevOps, PBI 105, Sprint 2.

## Historia

Como proveedor, quiero asignar empleados y recursos a los servicios de mi negocio, para definir qué personal y recursos pueden ser utilizados para realizar cada servicio y facilitar la gestión de las reservas.

## Criterios de aceptación

- El proveedor puede seleccionar un servicio registrado en su negocio.
- Puede asociar uno o varios empleados disponibles del mismo negocio.
- Puede asociar uno o varios recursos disponibles del mismo negocio.
- Puede definir si el servicio requiere empleados, recursos o ambos.
- Puede agregar o quitar empleados y recursos asociados.
- Evita asociaciones duplicadas del mismo empleado o recurso al mismo servicio.
- Tras guardar, el servicio muestra empleados y recursos asociados.
- Las asignaciones quedan disponibles para la gestión posterior de reservas.
