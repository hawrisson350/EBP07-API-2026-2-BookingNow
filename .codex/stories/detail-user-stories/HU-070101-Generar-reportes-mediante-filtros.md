# HU-070101 — Generar reportes mediante filtros

**Sprint:** 3  
**ID de Azure DevOps:** [87](https://dev.azure.com/CodeFactory-2026-2/EBP07%20-%20Plataforma%20de%20Reservas%20de%20Servicios/_workitems/edit/87)  
**Fuente:** Inventario recuperado del chat «Inventario HU Sprint 3»; asociado al elemento de Azure.

## Historia

Como administrador o proveedor del negocio, quiero generar reportes de reservas y de uso de servicios y recursos mediante filtros de búsqueda, para consultar información específica sobre la actividad del negocio.

## Criterios de aceptación registrados en Azure

- El usuario puede seleccionar el tipo de reporte:

- Reservas.

- Uso y consumo de servicios y recursos.

- El usuario puede aplicar filtros según el tipo de reporte, como:

- Rango de fechas.

- Servicio.

- Recurso.

- Estado de la reserva.

- El sistema genera el reporte de acuerdo con los filtros seleccionados.

- El reporte presenta la información correspondiente de manera organizada.

- Si no existen registros para los filtros seleccionados, el sistema informa que no hay resultados.

## Observaciones de análisis

Los criterios anteriores se conservan como fueron proporcionados por Azure DevOps. Las decisiones que no estén especificadas se registran como preguntas en el análisis asociado; esta ficha no agrega reglas nuevas.
