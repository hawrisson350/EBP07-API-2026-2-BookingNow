# HU-030102 — Buscar servicio por nombre y tipo

**Fuente:** Azure DevOps, PBI 63, Sprint 2.

## Historia

Como usuario, quiero buscar servicios por nombre o tipo, para encontrar fácilmente los servicios que sean de mi interés.

## Criterios de aceptación

- Permite ingresar palabras o parte del nombre para buscar un servicio.
- Permite seleccionar categoría o tipo para filtrar los resultados.
- Cuando se combinan nombre y tipo, los resultados corresponden a ambos criterios.
- Muestra los servicios que coinciden con la búsqueda.
- Usa paginación cuando el listado lo requiere.
- Si no hay coincidencias, informa que no se encontraron resultados.
- El usuario puede seleccionar un resultado para consultar su información.
